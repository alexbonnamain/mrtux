# Checklist de publicação — Mr Tux

1. Rode `python3 scripts/verificar_site.py`.
2. Rode `bash scripts/servir-local.sh`.
3. Confira a Home, Artigos, Softwares, Sobre, Contato e o artigo 01 em desktop e celular.
4. Confirme que o repositório publicado é `alexbonnamain.github.io` e que estes arquivos ficarão na raiz do Pages.
5. Envie todo o conteúdo deste diretório para a branch publicada pelo GitHub Pages.
6. Depois do deploy, abra `/feed.xml` e o artigo 01 diretamente pelo navegador.
7. Faça uma última conferência dos links externos e das imagens.

## Atenção editorial

A imagem `02.webp` foi mantida porque já fazia parte do projeto. O crédito aponta para a Hackaday, mas atribuição não equivale automaticamente a licença de republicação. Confirme a autorização/licença ou substitua a imagem antes da publicação se quiser eliminar esse risco.
